# Yasar C H — Portfolio

Personal portfolio of Yasar C H, Bachelor of Fashion Technology student at NIFT Jodhpur.

Built with Vite, vanilla JavaScript, GSAP + ScrollTrigger and Lenis. Hosted on Vercel.

```bash
npm install
npm run dev
```

- Content lives in `src/data.js`.
- Photos go in `public/images/` — see `public/images/README.md` for the file names.
